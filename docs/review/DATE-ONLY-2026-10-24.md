# Date-only planning confirmation - October 24, 2026

Application and test source: [`4ddf880920d72010b25a2e3f190c51e01051117a`](https://github.com/jlhpacheco/solvia/tree/4ddf880920d72010b25a2e3f190c51e01051117a).

Repeating visits now ask for **start date, end date and weekdays**. The redundant Number of weeks textbox is removed entirely, including hidden form inputs. One visit still asks only for its date. [Actual current form](Solvia-date-only-form.png).

## Behavior and compatibility

- Exact inclusive dates control visit counts. A partial final week never adds extra visits. Existing term, category, catalog-price and comparison-freshness checks remain authoritative.
- A description such as "Tuesdays for three weeks" becomes an editable end date. The AI schema and old HTTP/protected-draft contracts can retain weeks internally; the person does not answer a second duration question.
- Valid older weeks-only server drafts and same-person browser-history snapshots migrate to dates. A new deliberately blank end, malformed date, unknown duration or calendar overflow requires review. Switching to One visit disables recurrence controls.
- Back and Change the plan retain edits and invalidate old comparisons. Without JavaScript, repeating visits require an end date; one-visit mode changes use the existing protected POST.
- Schedule-reader and validation messages refer to the editable date choices. No price, payment or issuance authority was added to AI.
