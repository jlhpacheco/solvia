# October 19 review and fixes

This report describes the current Solvia changes. Earlier REDO-PLAN,
CHECK-REPORT, and CLEAN-INSTALL documents are historical records, not claims
that later dependency choices or external integrations were already tested.

## Fixed

- Registered college search providers and price repair in dependency injection.
  All College routes previously failed while creating `CollegeController`.
- Validate capture-level status, amount, currency, and capture ID before Paid
  or issuance; retain Pending captures for later verified webhooks.
- Restrict the demo payment client to PayPal's HTTPS sandbox endpoint and USD.
- Serialize new order creation with the SQLite write transaction and check
  concurrency before contacting PayPal, protecting the agreed price.
- Handle a capture/webhook race by returning the durable completed receipt;
  stale conflicting requests receive a useful retry response.
- Preserve webhook retries after transient database failure or an order that
  has not yet been saved; distinguish duplicates from genuine write failures.
- Prevent repricing an application with an open PayPal order.
- Validate vehicle edits and preserve plate/state once referenced by a permit.
- Read compound labels such as "license plate number" and numeric plates;
  preserve a stated plate if the model omits it and show missing-field guidance.
- Keep terminal/refunded/exempt permits out of payment links; use the current
  tab for checkout navigation.
- Apply the Solvia navy/teal design, responsive workspace, clear steps, visible
  demo disclosure, and accessible labels/focus behavior.
- Fix AG Grid's theme conflict and provide readable rows, wrapped source notes,
  quick search, accurate visible counts, and native fallback search.
- Replace the PDF dependency with MIT PDFsharp and Apache-2.0 embedded fonts.
- Pin PDFsharp's transitive PKCS dependency to patched 10.0.13
  ([Microsoft advisory](https://github.com/advisories/GHSA-846f-f764-76mx)).
- Replace external PDF-text tooling in tests with portable managed extraction.
- Correct privacy copy to describe the app host and configurable model endpoint.
